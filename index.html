About the Project

Making Indian legal information easier to explore.

NyayaLlama is a research and educational prototype that combines domain-focused fine-tuning with retrieval from selected Indian legal documents. The goal is to produce clearer, source-grounded explanations for legal-information questions.

📚

Legal Information

Designed to explain selected constitutional and statutory concepts in a simpler format.

🔎

Source Retrieval

Retrieves relevant pages from indexed legal documents before producing an answer.

💬

Interactive Questions

Users can ask questions through the live Gradio prototype.

Core Features

Fine-tuning meets legal retrieval.

🧠

Llama 3.2 3B

Uses Llama 3.2 3B Instruct as the base language model.

⚙️

LoRA Fine-Tuning

Adapts the model using parameter-efficient fine-tuning.

🔍

RAG Pipeline

Retrieves relevant legal pages using a TF-IDF based retrieval layer.

🇮🇳

Indian Legal Sources

Includes selected Constitution, BNS, BNSS and BSA source documents.

🛡️

Grounded Answers

The prototype uses retrieved legal context to reduce unsupported responses.

💻

Gradio Demo

Provides an interactive interface for testing the trained system.
